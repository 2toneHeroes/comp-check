# Comp Check

参考画像をカメラ映像や写真に重ねて、構図とライティングを確認するWebアプリ(依存ゼロ・単体HTML・PWA)。
構図が決まったら Blackmagic Camera や標準カメラに切り替えて撮る、という使い方を想定。

## 機能

- **比較対象**: 📷 カメラのライブ映像(カメラ切替・静止・ミラー) / 🖼 画像
  - 標準は背面の物理1xレンズ(iPhoneの「背面カメラ」)。俯瞰・卓上DIY撮影の定番の画角で、超広角のような歪みがない
  - 「デュアル」「トリプル」は距離でレンズが勝手に切り替わる仮想カメラなので標準にしない
  - 選択欄で選んだカメラは記憶して次回もそれで開く
- **参考画像**: 複数読み込み(画像 / ZIP)、ドラッグ&ドロップ、貼り付け。←→ で切替
  - yt-cut-analyzer(YouTubeショートのカット分析ブックマークレット) の書き出しZIPをそのまま読める
- **表示モード**: 重ね(透過スライダー、通常/差分合成) / 並べ(サイドバイサイド) / ワイプ(ドラッグで境界移動)
- **ガイド**: 3分割 / 黄金比グリッド(0.382・0.618) / 黄金スパイラル(↻で4方向) / セーフ(アクション93%・タイトル90%) / Shorts UI領域(目安: 上11%・下25%・右13%) / 中心
- **PNGガイド**: 透過PNG(テロップ位置・ロゴ位置など)をガイドとして重ねる。複数追加・個別にオンオフ・濃さ調整。端末に保存され次回も使える
  - フレームと同じ比率(9:16なら1080×1920)で作ると全面にぴったり重なる。比率が違う場合は中央に収める
  - **テンプレ**: 今の比率・今オンのガイドで透過PNGを書き出す。これを下敷きにPhotoshop/AEでテロップ位置を作る
- **ヒストグラム**: 参考と現在の輝度分布と平均輝度を重ねて表示(ライティング合わせ用)
- **比率**: 9:16 / 16:9 / 4:5 / 1:1
- **保存**: 表示中の画面をPNGで保存
- 設定は端末ごとに記憶

キーボード: ←→ 参考切替 / 1・2・3 表示モード

## 使い方

- PC: `index.html` をブラウザで開く(カメラは `localhost` か HTTPS のときだけ使える)
- iPhone / iPad: https://2toneheroes.github.io/comp-check/ を開く → 共有 > ホーム画面に追加

### YT Cutのサムネイルを iPhone に持ってくる

1. PCのYT Cutで「ZIP書き出し」→ 保存先にDropboxのフォルダを選ぶ(Chromeが覚えるので次回からそこが開く)
2. iPhoneのComp Checkで「参考を追加」→ ブラウズ → Dropbox → ZIPを選ぶ(iPhoneへの保存は不要)
   - ファイルAppの「ブラウズ」にDropboxが出ない場合は、… > 編集 でDropboxをオンにする

検索エンジンに載らないよう `noindex` と `robots.txt` を設定している。

## 必要な環境

- モダンブラウザ(Chrome / Safari / Edge)。依存ライブラリなし
- カメラ機能は HTTPS か `localhost` で開いたときのみ
