# Comp Check

参考画像をカメラ映像や写真に重ねて、構図とライティングを確認するWebアプリ(依存ゼロ・単体HTML・PWA)。
構図が決まったら Blackmagic Camera や標準カメラに切り替えて撮る、という使い方を想定。

## 機能

- **比較対象**: 📷 カメラのライブ映像(背面優先・カメラ切替・静止・ミラー) / 🖼 画像
- **参考画像**: 複数読み込み(画像 / ZIP)、ドラッグ&ドロップ、貼り付け。←→ で切替
  - yt-cut-analyzer(YouTubeショートのカット分析ブックマークレット) の書き出しZIPをそのまま読める
- **表示モード**: 重ね(透過スライダー、通常/差分合成) / 並べ(サイドバイサイド) / ワイプ(ドラッグで境界移動)
- **ガイド**: 3分割 / 黄金比グリッド(0.382・0.618) / 黄金スパイラル(↻で4方向) / セーフ(アクション93%・タイトル90%) / Shorts UI領域(目安: 上11%・下25%・右13%) / 中心
- **ヒストグラム**: 参考と現在の輝度分布と平均輝度を重ねて表示(ライティング合わせ用)
- **比率**: 9:16 / 16:9 / 4:5 / 1:1
- **保存**: 表示中の画面をPNGで保存
- 設定は端末ごとに記憶

キーボード: ←→ 参考切替 / 1・2・3 表示モード

## 使い方

- PC: `index.html` をブラウザで開く(カメラは `localhost` か HTTPS のときだけ使える)
- iPhone / iPad: GitHub Pages(HTTPS)で開く → 共有 > ホーム画面に追加

検索エンジンに載らないよう `noindex` と `robots.txt` を設定している。

## 必要な環境

- モダンブラウザ(Chrome / Safari / Edge)。依存ライブラリなし
- カメラ機能は HTTPS か `localhost` で開いたときのみ
