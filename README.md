# Comp Check

参考画像をカメラ映像や写真に重ねて、構図とライティングを確認するWebアプリ(依存ゼロ・単体HTML・PWA)。
構図が決まったら Blackmagic Camera や標準カメラに切り替えて撮る、という使い方を想定。

## 機能

- **比較対象**: 📷 カメラのライブ映像(カメラ切替・静止・ミラー) / 🖼 画像
  - 標準は背面の物理1xレンズ(iPhoneの「背面カメラ」)。俯瞰・卓上DIY撮影の定番の画角で、超広角のような歪みがない
  - 「デュアル」「トリプル」は距離でレンズが勝手に切り替わる仮想カメラなので標準にしない
  - 選択欄で選んだカメラは記憶して次回もそれで開く
- **参考画像**: 複数読み込み(画像 / ZIP)、ドラッグ&ドロップ、貼り付け。←→ で切替
  - yt-cut-analyzer(YouTubeショートのカット分析ブックマークレット) の書き出しZIPをそのまま読める
- **表示モード**: 重ね(透過スライダー、通常/差分合成) / 並べ(サイドバイサイド) / ワイプ(ドラッグで境界移動)
- **ガイド**: 3分割 / 黄金比グリッド(0.382・0.618) / 黄金スパイラル(↻で4方向) / セーフ(アクション93%・タイトル90%) / Shorts UI領域(目安: 上11%・下25%・右13%) / 中心
- **PNGガイド**: 透過PNG(テロップ位置・ロゴ位置など)をガイドとして重ねる。複数追加・個別にオンオフ・濃さ調整。端末に保存され次回も使える
  - フレームと同じ比率(9:16なら1080×1920)で作ると全面にぴったり重なる。比率が違う場合は中央に収める
  - **テンプレ**: 今の比率・今オンのガイドで透過PNGを書き出す。これを下敷きにPhotoshop/AEでテロップ位置を作る
- **ヒストグラム**: 参考と現在の輝度分布と平均輝度を重ねて表示(ライティング合わせ用)
- **比率**: 自動(縦持ち 9:16 / 横持ち 16:9) / 9:16 / 16:9 / 4:5 / 1:1
- **全画面**: ツールバーとサムネイル列を隠して映像だけにする。タップで操作ボタン(◀ ▶ / 透過 / ガイドの一時非表示 / 終了)が出て3秒で消える。全画面中は画面スリープを止める。キーボードは F
  - iPhoneはSafariのままだとURLバーが残る(ページの全画面化に非対応)。ホーム画面に追加して開くとURLバーも消える
- **iPad連携**: iPhoneのカメラ映像をiPadにライブで送り、iPad側で参考画像・ガイドを重ねて確認する(下記)
- **横向き**: スマホを横にすると、ツールバーを左・サムネイル列を右に並べ替える
- **保存**: 表示中の画面をPNGで保存
- 設定は端末ごとに記憶

キーボード: ←→ 参考切替 / 1・2・3 表示モード

## 使い方

- PC: `index.html` をブラウザで開く(カメラは `localhost` か HTTPS のときだけ使える)
- iPhone / iPad: https://2toneheroes.github.io/comp-check/ を開く → 共有 > ホーム画面に追加

### YT Cutのサムネイルを iPhone に持ってくる

1. PCのYT Cutで「ZIP書き出し」→ 保存先にDropboxのフォルダを選ぶ(Chromeが覚えるので次回からそこが開く)
2. iPhoneのComp Checkで「参考を追加」→ ブラウズ → Dropbox → ZIPを選ぶ(iPhoneへの保存は不要)
   - ファイルAppの「ブラウズ」にDropboxが出ない場合は、… > 編集 でDropboxをオンにする

検索エンジンに載らないよう `noindex` と `robots.txt` を設定している。

## iPad連携(iPhone → iPad ライブ映像)

```
iPhone ──(Tailscale / HTTPS)──┐
                               ├─ 自宅PCの中継サーバー signal/server.js(接続情報の受け渡しだけ)
iPad ───(Tailscale / HTTPS)──┘
iPhone ═══════ 映像(WebRTC・端末間で直接・暗号化) ═══════ iPad
```

- 映像は端末間で直接送る。中継サーバーを通るのは接続情報(SDP)だけ
- 中継サーバーはtailnet内だけに公開(`tailscale serve`)。外からは見えない
- 同じWi-Fiにいれば直接つながる

### サーバー側(自宅PC)

`signal/start-signal.bat` をダブルクリック(デスクトップにショートカットを置くと楽)。ウィンドウを閉じると止まる。
すでに起動していれば二重に起動せず、`tailscale serve` の設定も毎回確認する。
隣のフォルダに `yt-cut-analyzer` があれば、そのインストールページも `/ytcut/` で配る(`--static /ytcut=<dist>`)。

手動で起動する場合:

```bash
node signal/server.js 8790          # 127.0.0.1:8790 で待ち受け(依存なし)
tailscale serve --bg 8790           # https://<PC名>.<tailnet>.ts.net で tailnet に公開
```

初回は Tailscale 管理画面で Serve(HTTPS証明書)を有効にする必要がある。

### 使い方

1. iPhone・iPadとも Tailscale をオンにする
2. 中継サーバーのURLを設定する(各端末で1回): 「📡 iPad連携」に `https://<PC名>.<tailnet>.ts.net` を入れる。
   または `https://2toneheroes.github.io/comp-check/?sig=<URL>` で開くと自動で設定される
3. iPhone: 「📡 iPad連携」→「このカメラを送る」
4. iPad: 「📡 iPad連携」→「受信する」→ 一覧からiPhoneを選ぶ
5. iPadで参考画像を読み込むと、iPhoneの映像に重ねて確認できる

### PCで受信する

PCのChromeは、github.io のページから tailnet(100.x)への通信をローカルネットワーク制限で止めることがある。
そのため中継サーバーが comp-check 本体も `/app/` で配っている(同じオリジンになるので制限にかからない)。PCではこちらを開く:

```
https://<PC名>.<tailnet>.ts.net/app/?sig=https://<PC名>.<tailnet>.ts.net
```

送信側は20秒ごとに生存通知を送り、60秒途絶えた部屋(アプリが強制終了された等)はサーバーが片付ける。

## 必要な環境

- モダンブラウザ(Chrome / Safari / Edge)。依存ライブラリなし
- カメラ機能は HTTPS か `localhost` で開いたときのみ
